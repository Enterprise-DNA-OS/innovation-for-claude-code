# /shortlist

Compare weighted scores with reviewer coverage.

1. Read CLAUDE.md. Use current database output, never remembered figures.
2. Run:

```bash
npm run innovation -- shortlist
```

3. Present the findings with names and dates. State missing evidence and incomplete scorecards.

All commands accept --json. Actor names are attribution, not authentication. Do not rank partial scorecards as approved: two complete independent reviews are required.
