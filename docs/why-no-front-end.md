# Why no front end

An improvement programme coordinator can maintain ideas, scorecards, pilot decisions and outcome evidence by talking to a coding agent. The database owns the records; the agent runs the commands. Read-only HTML reports give the decision meeting something to read and print.

This base is useful for a trusted coordinator. It does not provide an employee submission portal, live discussions, drag-and-drop cards, mobile notifications, identity verification, single sign-on or a permission interface. Those are meaningful parts of a hosted idea platform. It is not a feature-equivalent replacement for every Ideanote deployment.

No messages send. Drafts and reports stay on disk. A local folder is not automatically a secure shared service. Add authenticated access, role restrictions, backup and restoration before team use. An actor name in a command is only an audit label. Never expose database-owner credentials to employees or browsers.

Enterprise DNA builds the required team submission screens and connections into a customised version through Omni by Enterprise DNA. The free base remains a database and commands. Your database can run on Postgres or embedded PGlite; Claude Code, Codex, OpenCode or Cursor can operate it.
